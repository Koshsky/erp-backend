# Changelog

Все заметные изменения этого проекта задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Fixed

- Сид-миграции больше не рассинхронизируют sequence (`V1017__sync_sequences.sql` выравнивает их); создание пользователей/ресурсов больше не падает с 409 на первичном ключе.

### Changed

- Автогенерируемые логины теперь в формате «фамилия.инициалы».
- Удаление пользователя возвращает 409 со списком ссылающихся записей.

## [1.0.0] - 2026-09-29

### Added

- Первый производственный релиз: слоистый Go/Gin-сервис, Casbin RBAC/ABAC, JWT-авторизация, домены планировщика/табеля/проектов, архивное мягкое удаление, аудит в Loki, трассировка OpenTelemetry.

### Changed

- Сид-миграции перенесены в `migrations/seed/` (фиксированные id, идемпотентность).
