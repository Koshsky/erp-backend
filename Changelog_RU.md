# Changelog

Все заметные изменения этого проекта задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3.0] - 2026-10-07

### Добавлено

- Сообщения об ошибках API локализованы по заголовку `Accept-Language` (русский по умолчанию, доступен английский).

## [1.2.0] - 2026-10-06

### Изменено

- Пресеты хранят три поля — тэг (код доступа), имя (отображаемое название) и описание; у встроенных пресетов русские имена.

## [1.1.0] - 2026-10-01

### Изменено

- Изменений в коде бэкенда нет; версия выровнена с волной фронтенда v1.1.0 (правило синхронизации MAJOR/MINOR).

## [1.0.2] - 2026-09-30

### Added

- Сброс пароля администратором теперь возвращает сгенерированный пароль в ответе (показывается один раз).
- Для состояний доступен свой цвет (`#RRGGBB`) при создании/изменении.

### Fixed

- Сид-миграции синхронизируют свои последовательности на месте, поэтому на свежих базах вставки без id больше не конфликтуют.
- Имена пресетов прав принимают буквы любого алфавита (в т.ч. кириллицу).

## [1.0.1] - 2026-09-30

### Fixed

- Сид-миграции больше не рассинхронизируют sequence (`V1017__sync_sequences.sql` выравнивает их); создание пользователей/ресурсов больше не падает с 409 на первичном ключе.
- Удаление пользователя больше не падает, если в сохранённом шаблоне автосоздания некорректный владелец процесса.

### Changed

- Автогенерируемые логины теперь в формате «фамилия.инициалы».
- Удаление пользователя возвращает 409 со списком ссылающихся записей.

## [1.0.0] - 2026-09-29

### Added

- Первый производственный релиз: слоистый Go/Gin-сервис, Casbin RBAC/ABAC, JWT-авторизация, домены планировщика/табеля/проектов, архивное мягкое удаление, аудит в Loki, трассировка OpenTelemetry.

### Changed

- Сид-миграции перенесены в `migrations/seed/` (фиксированные id, идемпотентность).
