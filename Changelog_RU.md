# Changelog

Все заметные изменения этого проекта задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.4.3] - 2026-11-11

### Изменено

- Административные права разделены по возможностям; миграция сохраняет старые разрешения и индивидуальные запреты.

## [1.4.2] - 2026-11-10

### Изменено

- Просмотр наследуется от проекта, процесса и задачи, включая явные запреты ниже; управление проверяется отдельно.
- V13 обновляет предустановленные роли и выделяет изменение приоритета проекта, сохраняя пользовательские роли и исключения.

- Для задач добавлен доступ по общему проекту; общий процесс охватывает все его задачи и подзадачи, а список, диаграмма и прямой доступ используют одинаковую область.

### Исправлено

- «Поддерево» проектов учитывает свои процессы и задачи; подсчёт доступных проектов использует ID текущего пользователя.
- Права процессов и задач для всех действий определяются владельцем родителя; V12 переносит существующие правила «Свои», сохраняя запреты.
- Проверяется смена владельца ресурсов; просмотр от лица пользователя доступен администратору только для чтения; владельцы процесса и назначаемого ресурса должны совпадать.
- Доступ к своим назначениям проверяет владельца ресурса, включая исторические назначения.
- При редактировании проверяются итоговый владелец и переносы вех и назначений, чтобы права «Свои» не позволяли работать с чужими объектами.
- Создание подзадачи проверяет доступ к родительской задаче и совпадение её процесса с указанным в запросе.

## [1.4.1] - 2026-11-09

### Изменено

- Бэкенд поставляет SQL внутри бинарника и использует golang-migrate с явным переносом истории Flyway без повторного применения плагинов.

## [1.4.0] - 2026-11-06

### Добавлено

- У проектов, процессов и задач появилось поле `responsible_id` — ответственный рядом с владельцем (существующие исполнители задач перенесены в него).

## [1.3.1] - 2026-10-13

### Изменено

- Аккаунт администратора больше не сидируется: он создаётся при первом запуске, пароль берётся из `ADMIN_PASSWORD`.

### Исправлено

- `GET /rbac/matrix` отдаёт полную матрицу всех пресетов (раньше — только admin); отсутствие права помечено `none`.

## [1.3.0] - 2026-10-07

### Добавлено

- Сообщения об ошибках API локализованы по заголовку `Accept-Language` (русский по умолчанию, доступен английский).

## [1.2.0] - 2026-10-06

### Изменено

- Пресеты хранят три поля — тэг (код доступа), имя (отображаемое название) и описание; у встроенных пресетов русские имена.

## [1.1.0] - 2026-10-01

### Изменено

- Изменений в коде бэкенда нет; версия выровнена с волной фронтенда v1.1.0 (правило синхронизации MAJOR/MINOR).

## [1.0.2] - 2026-09-30

### Added

- Сброс пароля администратором теперь возвращает сгенерированный пароль в ответе (показывается один раз).
- Для состояний доступен свой цвет (`#RRGGBB`) при создании/изменении.

### Fixed

- Сид-миграции синхронизируют свои последовательности на месте, поэтому на свежих базах вставки без id больше не конфликтуют.
- Имена пресетов прав принимают буквы любого алфавита (в т.ч. кириллицу).

## [1.0.1] - 2026-09-30

### Fixed

- Сид-миграции больше не рассинхронизируют sequence (`V1017__sync_sequences.sql` выравнивает их); создание пользователей/ресурсов больше не падает с 409 на первичном ключе.
- Удаление пользователя больше не падает, если в сохранённом шаблоне автосоздания некорректный владелец процесса.

### Changed

- Автогенерируемые логины теперь в формате «фамилия.инициалы».
- Удаление пользователя возвращает 409 со списком ссылающихся записей.

## [1.0.0] - 2026-09-29

### Added

- Первый производственный релиз: слоистый Go/Gin-сервис, Casbin RBAC/ABAC, JWT-авторизация, домены планировщика/табеля/проектов, архивное мягкое удаление, аудит в Loki, трассировка OpenTelemetry.

### Changed

- Сид-миграции перенесены в `migrations/seed/` (фиксированные id, идемпотентность).
